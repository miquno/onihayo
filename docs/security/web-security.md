## Changing the CSP

1. Prefer changing the code over widening the policy.
2. Never add `'unsafe-inline'` or `'unsafe-eval'` to `script-src`, or a wildcard or third-party origin anywhere, without an ADR.
3. Update this document and the threat model in the same pull request.
4. Run `pnpm test:e2e`; the console-error check catches violations.
