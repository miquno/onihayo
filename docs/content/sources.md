# Content source register

Every third-party source Onihayo uses or has evaluated. Licence information marked **to verify** is our current understanding and must be confirmed from the publisher's own licence page (import checklist step 2) before any data is committed.

## In use

None yet. No third-party learning data is in the repository.

## Excluded

| Source                                                                         | Reason                                                                                                            |
| ------------------------------------------------------------------------------ | ----------------------------------------------------------------------------------------------------------------- |
| WaniKani, Bunpro, Nihondex, and other commercial learning apps                 | Proprietary content                                                                                               |
| Commercial textbooks and workbooks (Genki, Minna no Nihongo, …)                | Proprietary content                                                                                               |
| Paid or proprietary dictionaries                                               | Proprietary content                                                                                               |
| Guides under NonCommercial licences (e.g. Tae Kim's Guide to Japanese Grammar) | NC terms are incompatible with free hosting choices ([ADR 0006](../decisions/0006-code-and-content-licensing.md)) |
| Any website without an explicit open licence                                   | Visible is not licensed; scraping is not allowed                                                                  |
